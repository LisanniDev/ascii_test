# Ascii Test Template

Шаблон для создания документации в формате Docs-as-Code с использованием AsciiDoc.

## Возможности
- Работа в VS Code
- Хранение в Git
- Переиспользование контента
- Использование переменных
- Модульная структура
- Генерация брендированного PDF
- CI/CD с GitHub Actions

## Установка

### 1. Установите зависимости
```bash
gem install asciidoctor
gem install asciidoctor-pdf
```

## Подключение проекта

- Открыть VS Code
- Открыть в  нём терминал (Ctrl+`)
- Выбрать директорию для клонирования репозитория:
```bash
cd путь-к-директории
```
- Клонировать репозиторий:
```bash
git clone https://ссылка-на-проект
```
- Открыть склонированную папку: File - Open Folder

## Применение внесённых изменений на Git-репозиторий

- Открыть панель Source Control
- Кратко описать внесённые изменения в строке Message (обязательно!)
- Нажать кнопку Commit & Push из выпадающего списка
