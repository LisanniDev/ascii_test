= Ascii Test Template

Шаблон и инструкция для создания документации в формате Docs-as-Code с использованием AsciiDoc.

== Возможности
- Работа в VS Code
- Хранение в Git
- Переиспользование контента
- Использование переменных
- Модульная структура
- Генерация брендированного PDF
- CI/CD с GitHub Actions

== Установка

=== 1. Установка Ruby
* Скачать с сайта https://rubyinstaller.org/downloads/ версию Ruby+Devkit
* Установить скачанный exe-файл, выбрав в конце установки "Run ridk install..."
* В открывшейся консоли выбрать пакет 3 для установки MSYS2+MINGW

=== 2. Установка зависимостей
Установка зависимостей и плагинов выполняется в командной строке, открытой от имени администратора.

. Основной плагин Asciidoctor
+
[source,console]
....
gem install asciidoctor
....
. Плагин asciidoctor-pdf
+
[source,console]
....
gem install asciidoctor
....
. Плагин подсветки синтаксиса кода
+
[source,console]
....
gem install rouge
....
. Плагин для расширенной работы с таблицами
** Скачать и разместить локально файл link:curs-asciidoctor-extensions-0.1.0.gem[curs-asciidoctor-extensions-0.1.0.gem]
** В командной строке перейти в директорию, куда был сохранён файл:
+
[source,console]
....
cd путь-к-директории-файла
....
** Выполнить команду установки плагина:
+
[source,console]
....
gem install curs-asciidoctor-extensions-0.1.0.gem
....


== Подключение проекта

* Открыть VS Code
* Открыть в  нём терминал (`Ctrl+\``)
* Выбрать директорию для клонирования репозитория:
+
[source,console]
....
cd путь-к-директории
....
* Клонировать репозиторий:
+
[source,console]
....
git clone https://github.com/your-company/название-репозитория.git
....
* Открыть склонированную папку: `File - Open Folder`

== Применение внесённых изменений на Git-репозиторий

* Применить изменения в локальной директории (`Ctrl+S`)
* Открыть панель `Source Control`
* Кратко описать внесённые изменения в строке `Message` (обязательно!)
* Нажать кнопку `Commit`, а затем `Sync Changes`
