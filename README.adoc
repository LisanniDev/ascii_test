= Ascii Test Template

Шаблон для создания документации в формате Docs-as-Code с использованием AsciiDoc.

== Возможности
- Работа в VS Code
- Хранение в Git
- Переиспользование контента
- Использование переменных
- Модульная структура
- Генерация брендированного PDF
- CI/CD с GitHub Actions

== Установка

=== 1. Установка Ruby
* Скачать с сайта https://rubyinstaller.org/downloads/ версию Ruby+Devkit
* Установить скачанный exe-файл, выбрав в конце установки "Run ridk install..."
* В открывшейся консоли выбрать пакет 3 для установки MSYS2+MINGW

=== 2. Установка зависимостей
Открыть консоль от имени администратора и выполнить:

. Установить основной плагин Asciidoctor
+
[source,console]
....
gem install asciidoctor
....
. Установить плагин asciidoctor-pdf
+
[source,console]
....
gem install asciidoctor
....

== Подключение проекта

* Открыть VS Code
* Открыть в  нём терминал (**Ctrl+`**)
* Выбрать директорию для клонирования репозитория:
+
[source,console]
....
cd путь-к-директории
....
* Клонировать репозиторий:
+
[source,console]
....
git clone https://github.com/your-company/название-репозитория.git
....
* Открыть склонированную папку: **File - Open Folder**

== Применение внесённых изменений на Git-репозиторий

* Применить изменения в локальной директории (**Ctrl+S**)
* Открыть панель **Source Control**
* Кратко описать внесённые изменения в строке Message (обязательно!)
* Нажать кнопку **Commit & Push** из выпадающего списка
